当前《心猿》Windows 试玩版以本地单机方式运行。游戏进度与设置保存在您的电脑上；游戏客户端目前没有开发者运营的账号系统、云存档、广告、支付或联网行为统计，也不会自动向开发者上传存档或运行日志。您主动发送的反馈信息仅用于处理相应请求。

一、适用范围

本政策适用于由 yanwujie 开发的《心猿》Windows 试玩版游戏客户端，以及您向本政策所列邮箱主动提交的隐私或故障反馈。游戏原开发名称为《西游·悟空闯黑风》，部分本地文件夹可能仍使用该名称。

TapTap 客户端、账号、下载、社区及其他平台服务由相应平台提供，其个人信息处理活动适用平台自己的隐私政策，不由本游戏代为控制。本政策不代表平台服务不收集信息。

二、处理哪些信息以及为什么

信息类别内容与用途保存位置及获取方式
游戏进度关卡解锁、通关与评分、修为和技能点、装备及穿戴/锁定状态、灵蕴、掉落记录与保底、出阵符祝等，用于继续游戏和保持进度一致。由游戏过程中产生，保存为电脑本地存档及备份，不自动上传。
游戏设置按键、音量、静音、显示及效果设置，用于记住您的操作偏好。由您的设置操作产生，保存于本机设置存储区（包括 Windows 用户注册表）。
本地运行日志引擎启动、图形设备、错误与文件路径等诊断信息，可能含电脑用户名或系统环境信息，用于本机故障定位。由 Unity/系统在本机生成。本游戏不自动上传；开发者仅在您主动提供时收到相应内容。
主动反馈您通过邮件提交的邮箱地址、问题说明及自选附件，用于回复、排查故障和处理隐私请求。由您主动发送，由开发者接收；邮件服务商按其服务规则处理传输和存储。

游玩当前版本无需向游戏客户端提供姓名、身份证号、电话号码、通讯录、精确位置或支付信息；游戏不主动申请相机、麦克风、通讯录或定位权限。按键输入用于当前游戏控制，不记录系统级键盘输入。

请在发送截图、日志或存档前检查内容，遮盖不相关的个人信息。我们不会要求您发送账号密码、验证码、支付密码或身份证照片来排查普通游戏问题。

三、存储、期限与安全

本地游戏存档通常位于 Windows 用户目录的 AppData\LocalLow\Ink Journey Prototype 下，以 equipment-v1.xml 保存，并可能有 .bak 备份。分享版可能使用 Share-Volume1 子目录。具体路径随构建版本和系统环境有所不同。设置与运行日志也保存在本机相应目录或设置存储区。

本地数据由您控制，可保留至您删除。卸载或删除游戏程序不一定会一并删除这些数据；删除存档和备份后，进度可能无法恢复，请先自行备份。本地存档不是加密保险箱，请妥善保护您的电脑账户与备份。

对于您主动发送的反馈，我们仅在处理问题、完成后续沟通或履行适用法律义务所必需的期间保留相关信息；目的达到后删除或去标识化。您可随时联系开发者申请删除不再需要的反馈材料。我们不会把反馈信息用于广告营销或建立玩家画像。

开发者将采取合理的访问限制与必要的安全措施保护收到的信息。如发生影响个人信息安全的事件，将根据适用要求采取补救措施并通知受影响用户或有关部门。

四、第三方组件、共享与跨境

游戏使用 Unity 引擎处理画面、声音、输入与本地文件。当前版本未接入广告、支付、社交登录或云分析 SDK；Unity Analytics、云崩溃诊断及广告服务在项目配置中均为关闭状态。

我们不出售或出租个人信息，不将本地游戏数据自动发送给第三方。若依法需要提供信息、为处理您的明确请求需要提供信息，或经您另行授权，将仅在相应范围内处理。

通过 TapTap 获取游戏、浏览本隐私政策网页或发送邮件时，相关平台、网页托管和邮件服务提供方可能处理连接所需的 IP 地址、浏览器/客户端信息及服务日志；这些独立服务不等同于游戏客户端的数据采集。本网页自身不包含表单、广告、分析脚本或主动设置 Cookie 的代码。

游戏客户端没有将本地存档或日志跨境传输的功能。您主动通过 Gmail 联系开发者时，邮件可能由境外服务设施处理；请仅提交解决问题所必需的信息。如果未来游戏新增涉及个人信息的联网服务或跨境处理，将先更新说明，并按适用要求另行告知或取得同意。

五、您的选择与权利

  • 您可以在游戏设置中修改操作和显示偏好，并在电脑上备份或删除本地存档。因开发者没有收到本地数据，无法远程读取、删除或恢复这些数据。
  • 您可以选择不发送反馈附件；这不会影响本地单机游戏功能，但可能限制问题排查。
  • 对于开发者实际持有的反馈信息，您可以通过下方邮箱请求访问、复制、更正、删除、撤回相应授权，或要求解释处理规则。
  • 为防止他人冒用，可能需要您通过原联系邮箱确认请求。我们仅核验处理请求所必需的信息，并在适用法律要求的期限内答复。
  • 当前游戏没有开发者账号，因此不存在游戏账号注册或注销流程。TapTap 等平台账号的相关请求请向平台提出。

六、未成年人保护

未成年人应在监护人指导下阅读本政策、合理安排游戏时间。开发者不会主动通过当前单机客户端收集未成年人的身份信息。未满十四周岁的用户如需提交含个人信息的反馈，应由监护人代为联系或在监护人同意下进行。监护人发现相关信息被不当提交时，可联系开发者处理和删除。

七、政策更新

游戏功能或信息处理方式发生变化时，我们将更新本页面及日期。涉及新增个人信息处理目的、类型或接收方等重要变化，将通过游戏版本说明、平台公告或适当方式告知；需要另行同意的，不以本政策更新代替同意。后续版本不自动适用当前版本未具备的联网功能描述。
